## 1. 퀴즈 포털 SEO (검색 엔진 최적화) 전략

### 1.1. 타깃 검색 키워드 체계
* **메인 키워드 (오가닉 볼륨):** `상식 퀴즈`, `1일 1상식`, `30초 두뇌 퀴즈`, `두뇌 테스트`, `스낵 퀴즈`
* **롱테일 키워드 (쇼츠 콘텐츠 연동):** `비행기 창문 구멍 이유`, `얼음 물 무게 비교`, `사관 사초 왕 열람`, `가장 넓은 사막`
* **타깃 검색 의도:** 출퇴근길 가벼운 킬링타임 및 쇼츠 시청 후 "진짜일까?"를 확인하려는 지식 탐색 유저 유입.

### 1.2. On-Page SEO 기술 사양 (구현 완료)
1. **시맨틱 HTML5 구조:** `<main>`, `<header>`, `<section>`, `<aside>` 명확 분리 및 WCAG 2.1 접근성 준수.
2. **Open Graph / Twitter Card:** 소셜 공유 시 썸네일과 설명문 자동 노출 메타태그 구성.
3. **구조화된 데이터 (Schema.org JSON-LD):** Google 검색엔진 리치 결과(Rich Snippet)를 타깃으로 `Quiz`, `Question`, `Answer` 스키마 마크업 내장.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Quiz",
  "name": "notopened 1일 1상식 두뇌 퀴즈",
  "description": "과학, 역사, 지리 등 일상 속 흥미진진한 상식 5문항 퀴즈",
  "educationalLevel": "Beginner",
  "about": {
    "@type": "Thing",
    "name": "General Knowledge & Science"
  }
}
</script>
```

## 2. Google AdSense 정책 및 사전 승인 체크리스트

AdSense 신청 시 '가치 없는 콘텐츠(Thin Content)' 또는 '무효 트래픽' 거절을 원천 차단하기 위한 5대 사전 요건:

| 점검 항목 | 구체적 기준 및 준수 계획 | 현재 상태 |
| :--- | :--- | :---: |
| **1. 필수 정적 페이지** | 개인정보처리방침(Privacy Policy), 이용약관, 문의처(Contact) 링크 구비 | **작성 예정 (템플릿 준비)** |
| **2. 콘텐츠 양적 기준** | 최소 30~50개 이상의 고유하고 검증된 퀴즈 DB 구축 후 심사 신청 | **진행 중 (5개 완료, 하루 샘플 3개 추가)** |
| **3. 무효 클릭 방지** | 배너 슬롯과 조작 버튼 간 최소 20px 이상 간격 확보 (오클릭 방지) | **완료 (CSS 마진 24px 적용)** |
| **4. 모바일 레이아웃** | 모바일 상단 300x250 전면 가림 금지 ➔ 320x50 또는 300x100 스마트 배너 규격 적용 | **완료 (320x50 규격 배치)** |
| **5. ads.txt 인프라** | 도메인 루트 디렉터리에 `ads.txt` 파일 서빙 파이프라인 확보 | **대기 (도메인 승인 시 연동)** |

## 3. 무료 호스팅 인프라 및 운영비(Run-rate) 검토

* **호스팅 옵션 비교:**
  * **Option A: GitHub Pages (최우선 권장)**: 월 트래픽 100GB 무료, 정적 사이트 최적화, 배포 자동화 용이.
  * **Option B: Cloudflare Pages**: 무제한 대역폭, 전 세계 300개 Edge CDN 캐싱, DDoS 방어 무료.
* **도메인 연결 전략:**
  * **1단계 (내부 검증기):** 무료 제공 서브도메인 활용 (`penta309.github.io/quiz`) ➔ 비용: **₩0**
  * **2단계 (공식 수익화 승인 시):** 단독 도메인 연결 (연간 약 15,000~20,000원 소요 추정) ➔ **회장 사전 승인 필수**.
* **재무 총평:** 승인 전까지 월 추가 고정비는 **₩0/월**로 완벽히 통제됨.

## 4. 하이디(CCO 겸 CFO) 전담 분석 KPI 정의

하이디 CFO가 전사 재무 원장 및 CCO 보고서에 통합 관리할 5대 핵심 지표:

1. **DAU / UV (일일 순방문자수):** 하루 유튜브 숏폼 댓글 유입 vs 포털 검색 오가닉 유입 비중 (초기 목표: 일 100명).
2. **Quiz Completion Rate (퀴즈 완주율):** 1번 문제 진입 대비 5번 결과 화면 도달 비율 (목표: 65% 이상).
3. **Avg. Session Duration (평균 체류시간):** 퀴즈 풀이 및 해설 열람 시간 (목표: 45초~90초, AdSense 노출 유효성 충족).
4. **Social Share CTR (결과 공유율):** '결과 복사하기' 버튼 클릭 비율 (목표: 5% 이상).
5. **Game Cross-Promotion CTR (게임 다운로드 클릭률):** 하단 GAME #001 / #003 체험하기 버튼 클릭 비율 (목표: 3% 이상).
6. *(AdSense 승인 후)* **Page RPM & eCPM:** 1,000회 페이지뷰당 실측 광고 매출.
